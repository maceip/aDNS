# Native acceptance secondary VM

The isolated native acceptance deployment uses a stock BIND secondary at **20.166.33.141**, serving public TCP and UDP port 53. Azure ACI rejected duplicate port 53 declarations for the two protocols, so the DNS frontend runs on a separate VM in the same validation resource group. CCF and the two attested service workers remain confidential ACI workloads. This fallback changes only the untrusted DNS frontend: it receives signed zones using TSIG and holds no DNSSEC private key.

## Actual deployment

The VM `agentdns-secondary-vm` is in `agentdns-port-validation-20260913`, North Europe. It uses `Standard_EC2as_v5` (2 vCPU, 16 GiB) and Canonical's `ubuntu-24_04-lts:cvm:24.04.202608260` image. Ordinary small x64 SKUs were unavailable under this subscription; the first DC2as_v6 attempt failed its zero family quota and was preserved as a failed attempt. The chosen EC2as_v5 allocation succeeded. Its confidential-VM hardware is incidental to the frontend deployment; the service does not trust or appraise this VM, and this is not a migration of the CCF or worker attestation profiles.

The VM pulled the existing immutable image `agentdnsport20260913.azurecr.io/secondary@sha256:dfd9158f60a9a0cd67b445b001ee636a0389c66ce926af3c386588d886976861` through the existing managed pull identity. Actual runtime versions are Docker 29.1.3 and BIND 9.18.39-0ubuntu0.24.04.7-Ubuntu. The image was neither rebuilt nor modified for this fallback. The [provisioning helper](../tools/secondary_vm.py) checks the exact pulled digest before starting stock `named`.

Runtime TSIG material is provisioned through encrypted VM extension protected settings and retained in a mode-0600 include owned by the BIND user. Registry tokens remain in memory or a temporary Docker configuration removed after the pull. No credentials are embedded in the image or public evidence. Public SSH is closed; management uses Azure VM Run Command. Public NSG rules and Docker publishes expose only TCP/UDP 53. The read-only container has one CPU, a 512 MiB memory limit and 64-process limit.

The authoritative `example.test` secondary disables recursion, outbound zone transfers and autosigning. It uses the governed `agentdns-transfer.` TSIG key for AXFR from the confidential primary's TCP 5353 listener. `allow-notify` authorizes that TSIG identity independently of the packet's source address, accommodating a distinct ACI outbound NAT address. Only actual authenticated served-serial observations can establish successful transfer/NOTIFY operation.

The [bounded collector](../tests/rust-integration/observe_native_bind.py) records the actual `named` PID1's `/proc` VmRSS and VmHWM in KiB, verifies its process start identity throughout, and separately samples container-root cgroup-v2 aggregate memory in bytes. The aggregate is memory charged by the kernel to this cgroup, including collector charges and charged cache; it is not process RSS or the sum of process RSS values. Shared-page ownership can differ from process residency, as described in the [kernel cgroup-v2 memory documentation](https://cdn.kernel.org/doc/html/latest/admin-guide/cgroup-v2.html#memory). Runtime probing confirms `memory.current` and `memory.peak` are available. The collector records its own CPU time, maximum RSS and maximum counter-read duration. VmHWM and memory.peak are existing process/cgroup high-water counters and may include earlier activity; no counter is reset. Window maxima must be calculated from the sampled VmRSS and memory.current values. The coordinated 1380-second run produces 139 nominal samples; a separate outer timeout terminates it by 1450 seconds. Its 180-second duration margin allows for VM Run Command dispatch/return latency around the 1200-second DNS load. The report must identify the actual overlapping interval rather than assume simultaneous starts. All raw sample files will be retrieved in hashed chunks to avoid Azure Run Command output truncation. This observation does not prove leak freedom. Collection starts only for the coordinated mutation-free acceptance window.
